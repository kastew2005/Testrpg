# Пепел королевства — Telegram Mini App

## Состав
- `index.html` — экраны создания героя, мира, боя, героя и меню.
- `styles.css` — мобильный тёмно-фэнтезийный интерфейс.
- `canvas-avatars.js` — процедурные Canvas-портреты рас.
- `app.js` — бой, карта, туман войны, уровни, добыча, автосохранение.

## Запуск
Откройте `index.html` в современном браузере. Для Telegram Mini App разместите все четыре файла в одной папке на HTTPS-хостинге и укажите URL в настройках бота через @BotFather.

Игра использует localStorage этого браузера. Для синхронизации прогресса между устройствами нужен сервер. Шрифт загружается с Google Fonts, а Telegram SDK — с официального адреса; при их недоступности игра использует системные шрифты и продолжает работать.

## Архив
В корне проекта есть `download-project.html` — откройте его в браузере, чтобы скачать ZIP-архив исходников прямо со страницы (JSZip загружается с CDN).
